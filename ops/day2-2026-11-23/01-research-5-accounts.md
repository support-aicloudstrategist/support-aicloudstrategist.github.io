# Day 2 — Research: 5 more ICP accounts
Date: 2026-11-23 | Owner: Rajiv

ICP filter: product SaaS / AI product; AWS/Azure/GCP + K8s and/or GPU; bill/ownership pain; buyer = VP Eng / Platform / FinOps / Cloud.

## 1) CleverTap
- **Why ICP:** Product analytics / engagement SaaS at scale; multi-region cloud; shared data platform costs often lack a single owner.
- **Likely buyer:** Head of Platform / VP Engineering / Cloud Ops.
- **Trigger to probe:** Multi-cloud or multi-region infra spend; shared analytics pipeline vs product-line ownership.
- **Channel:** LinkedIn → Platform / Eng leadership.
- **Fit angle:** Ownership map before another optimization pass on shared data/cloud pools.

## 2) Darwinbox
- **Why ICP:** HR SaaS product company; cloud growth with product modules; classic showback vs ownership gap.
- **Likely buyer:** Head of Infra / VP Eng / FinOps-adjacent ops.
- **Trigger to probe:** Module-level cost fights; Kubernetes shared cluster attribution.
- **Channel:** LinkedIn → Infra / Platform.
- **Fit angle:** Fixed-fee diagnostic → assigned / shared / unallocated before cuts.

## 3) Innovaccer
- **Why ICP:** Health data / AI platform; cloud + data estate; AI/analytics spend without clear product owners is common.
- **Likely buyer:** VP Eng / Cloud COE / Platform lead.
- **Trigger to probe:** Data platform + AI workload spend; shared vs product allocation.
- **Channel:** LinkedIn → Eng / Cloud leadership.
- **Fit angle:** Name owners before commit or cut on contested platform lines. (No PHI, no credentials in outreach.)

## 4) Whatfix
- **Why ICP:** Enterprise SaaS; multi-product cloud footprint; scale engineering org.
- **Likely buyer:** Head of Platform / SRE / FinOps.
- **Trigger to probe:** Shared platform bill debates; reliability vs cost ownership.
- **Channel:** LinkedIn → Platform / SRE.
- **Fit angle:** Diagnostic that separates ownership from dashboards.

## 5) Sprinklr
- **Why ICP:** Large product SaaS; heavy cloud/AI surface; board-visible spend pressure possible.
- **Likely buyer:** VP Eng / Head of Cloud / FinOps lead.
- **Trigger to probe:** AI/feature spend without named owners; multi-cloud governance.
- **Channel:** LinkedIn → Eng / Cloud / FinOps.
- **Fit angle:** Owners + act/investigate/hold before savings programs.

Public ICP fit only — no scraped personal emails, no fabricated buyer names. Rajiv resolves exact LinkedIn profiles before send.
