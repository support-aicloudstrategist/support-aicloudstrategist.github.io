Fixed-scope diagnostic package

1. Spend-source inventory

Map AWS, Azure, Google Cloud, hosting, LLM/API, GPU, vector database, monitoring, logging and SaaS vendor invoices or exported summaries. Read-only or exported evidence is preferred.

2. Allocation and owner gap report

Identify where spend lacks owner, product, customer, environment, region, data-boundary or approval metadata. The output is a prioritized evidence backlog, not a savings guarantee.

3. Cloud trust evidence checklist

Review access, MFA, admin ownership, backup evidence, restore-test notes, vendor/renewal list, incident path, logging gaps and data-boundary questions for qualified adviser review.

4. CFO/CTO decision cadence

Create a UAE-friendly monthly review pack with top cost movements, AI spend review, owner actions, risk flags, deferred decisions and next-step approvals.
