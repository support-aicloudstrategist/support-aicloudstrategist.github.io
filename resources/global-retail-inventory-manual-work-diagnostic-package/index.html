FAQ

Can this run without production POS or ERP access?

Yes. Initial scope can use redacted screenshots, field names, sample templates and owner interviews. Do not send passwords, tokens, payment data or customer data for first scope.

Is this a guarantee that inventory will improve?

No. This package prepares evidence, owner handoffs and safe decision boundaries. Any stock accuracy, stockout, margin, revenue, savings or ROI claim would need separately verified measurement.
