Top-3/top-5 consideration checklist

1. Spend-source inventory

List AWS accounts, Azure subscriptions, GCP projects, Kubernetes clusters, LLM/API vendors, GPU providers, vector databases, monitoring tools and commitment contracts.

2. Allocation and owner coverage

Measure which spend rows have product, customer, environment, workload, finance owner, engineering owner and review status.

3. AI cost separation

Separate LLM tokens, embeddings, inference, training, agents, GPU jobs, retrieval and observability overhead from generic cloud cost.

4. GDPR-aware evidence boundary

Use exported/read-only billing evidence where possible, redact personal or confidential identifiers and route legal/privacy/security questions to qualified advisers.

5. Decision log and waste register

Track every anomaly or optimisation candidate with owner, evidence link, risk, decision status, next date and whether action requires production-change approval.

6. CFO/CTO review rhythm

Create a monthly one-page review: movement, owner gaps, blocked actions, AI cost drivers, commitment questions and next sprint backlog.
