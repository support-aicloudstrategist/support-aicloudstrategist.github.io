# Structured content — Automation Exception Queue Map

## Title
Automation Exception Queue Map: 7 labels before a human hands work to AI

## Learning objectives
- Help teams classify routine work and exceptions before AI-assisted follow-up.
- Keep sensitive, missing-context, upset-customer, and owner-review items visible.
- Keep the guidance educational and claim-safe.

## Sections

### 1. Routine
Content: Approved facts, simple status updates, and low-risk reminders that match current team rules.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Routine; exception label.

### 2. Needs owner
Content: Pricing, refunds, contracts, promises, unusual requests, or anything the team has not approved.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Needs owner; exception label.

### 3. Sensitive
Content: Personal data, health, finance, identity, credentials, OTPs, access, or private documents.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Sensitive; exception label.

### 4. Missing context
Content: The request cannot be answered safely because source, record, timestamp, or owner note is missing.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Missing context; exception label.

### 5. Customer upset
Content: Complaint, escalation, urgent tone, repeated follow-up, or a promise that may already be late.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Customer upset; exception label.

### 6. Evidence saved
Content: Conversation link, source system, status, owner, next step, and timestamp are recorded.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Evidence saved; exception label.

### 7. Human reply
Content: A named person reviews the exception before any external answer or customer commitment.
Visual element: Labeled queue node connected to a central review hub.
Text labels: Human reply; exception label.

## Data points
- No statistics used.
- No customer examples used.
- No performance claims used.

## Boundary label
Educational workflow only — no legal, compliance, medical, financial, security, certification, savings, ranking, revenue, booking, or guaranteed-performance advice.
