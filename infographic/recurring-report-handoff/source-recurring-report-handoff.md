# Still Building the Same Report by Hand? A 6-Step Automation Handoff

Use this educational handoff before automating a recurring business report.

1. **Name the decision.** Write the decision this report supports and the person who owns that decision.
2. **List the sources.** Record each approved source, its owner, update timing and access path.
3. **Define the rules.** Write the calculation, filter, grouping and exception rules in plain language.
4. **Mark the checks.** Identify who reviews the output, what they check and what evidence is retained.
5. **Set the fallback.** Define what happens when data is missing, late, duplicated or inconsistent.
6. **Choose the release gate.** Run the automated and manual versions together; release only after the authorized owner accepts the comparison.

Minimum handoff record: decision · decision owner · approved sources · source owners · update timing · calculation rules · exception rules · reviewer · retained evidence · fallback · comparison period · release owner.
