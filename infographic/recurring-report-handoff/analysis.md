## Main Topic
A safe educational handoff for defining ownership, inputs, rules, review, fallback and release controls before automating a recurring business report.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. How to document a recurring report before automation.
2. Where human ownership and review remain necessary.
3. What minimum evidence should accompany a release decision.

## Target Audience
- **Knowledge Level**: Beginner to intermediate business and operations owners
- **Context**: Repetitive report preparation is consuming time or producing inconsistent handoffs
- **Expectations**: A practical, non-technical sequence that can be used in a planning discussion

## Content Type Analysis
- **Data Structure**: Six sequential steps followed by one minimum-record takeaway
- **Key Relationships**: Each step supplies evidence required by the next; release follows a manual-versus-automated comparison
- **Visual Opportunities**: Numbered nodes, source icons, rule card, review checkpoint, fallback branch and release gate

## Key Data Points (Verbatim)
- "Name the decision."
- "List the sources."
- "Define the rules."
- "Mark the checks."
- "Set the fallback."
- "Choose the release gate."
- "Run the automated and manual versions together; release only after the authorized owner accepts the comparison."
