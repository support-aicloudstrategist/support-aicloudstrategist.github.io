# AI Automation for Small Business: Owner Checklist Before Buying a Tool

## Overview
A no-credentials, synthetic checklist covering trigger, owner, rules, exceptions and the smallest evidence-matched next move.

## Learning Objectives
The viewer will understand:
1. Which five workflow questions to answer before buying an AI tool.
2. How to separate repeatable rules from judgement and exceptions.
3. Why the first move should be small, reversible and evidence-matched.

---

## Section 1: Name the repeatable job
**Key Concept**: Define the workflow trigger and output.
**Content**:
- “When a web enquiry arrives someone copies it into a sheet”
- Define trigger and output
- Use synthetic example only
**Visual Element**: Numbered card with an inbox-to-sheet hand-drawn icon.
**Text Labels**: “1”, “NAME THE REPEATABLE JOB”, “TRIGGER + OUTPUT”

## Section 2: Find the accountable owner
**Key Concept**: Name the person accountable for the output.
**Content**:
- “Operations lead reviews the queue”
- Name accountable owner
- No personal data
**Visual Element**: Numbered card with a person and ownership badge.
**Text Labels**: “2”, “FIND THE ACCOUNTABLE OWNER”, “OWNER”

## Section 3: Separate rules from judgement
**Key Concept**: Distinguish stable rules from human judgement.
**Content**:
- “Assign by service type; escalate unknowns”
- Separate judgement
- Human review for exceptions
**Visual Element**: Split-path icon for rules and human review.
**Text Labels**: “3”, “SEPARATE RULES FROM JUDGEMENT”, “RULES / REVIEW”

## Section 4: Define the stop path
**Key Concept**: Make exceptions pause and escalate safely.
**Content**:
- “Missing details or sensitive request”
- Write stop and escalation path
- No regulated or payment data
**Visual Element**: Stop sign leading to a human-review icon.
**Text Labels**: “4”, “DEFINE THE STOP PATH”, “STOP + ESCALATE”

## Section 5: Choose the smallest next move
**Key Concept**: Start with a reversible experiment.
**Content**:
- “Test a checklist with synthetic rows”
- Run reversible experiment
- No ROI or savings promise
**Visual Element**: Small test tube/checklist icon with a return arrow.
**Text Labels**: “5”, “CHOOSE THE SMALLEST NEXT MOVE”, “REVERSIBLE TEST”

## Decision Rule
**Content**:
- A small business should define the repeatable job, accountable owner, rule-versus-judgement steps, exception stop path and reversible evidence-matched next move before selecting AI automation.
**Visual Element**: Wide highlighted summary cell.
**Text Labels**: “BEFORE YOU BUY A TOOL”
