# Before You Buy an AI Tool: A 6-Box Pilot Brief

Use this educational brief to define a small, reviewable pilot before choosing an AI tool.

1. **Business task** — Name one task, its current owner, the trigger that starts it and the output that marks it complete.
2. **Evidence baseline** — Record current time, error, rework or queue evidence using a consistent method. If no baseline exists, observe first.
3. **Data boundary** — List the data the pilot may use, the data it must not use and the approved storage or access path.
4. **Human control** — Identify who reviews outputs, what requires approval and when the workflow must stop or return to a person.
5. **Pilot measure** — Choose one observable process measure and one quality check. Define how both will be recorded.
6. **Exit decision** — At the review date, choose: proceed, revise or stop. Record the evidence and owner for the next decision.

Minimum pilot record: task · owner · trigger · baseline · allowed data · restricted data · reviewer · stop condition · process measure · quality check · review date · exit decision

Proof boundary: Educational pilot-planning material only — not a client case study, performance guarantee, security assessment, legal or compliance advice, procurement recommendation or production-change instruction.
