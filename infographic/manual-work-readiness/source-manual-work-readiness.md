# Too Much Manual Work? A 5-Check Automation Readiness Map

Use this educational map before automating a repetitive business workflow.

1. **Name the workflow** — Write one clear start event, one end result and the person who owns the outcome.
2. **Map the handoffs** — Mark every system, person, queue and approval the work passes through.
3. **Check repeatability** — Separate stable rules from judgment calls, rare cases and missing information.
4. **Protect the exceptions** — Define when automation must stop, ask for review or return work to a human owner.
5. **Choose the next move** — AUTOMATE when rules and evidence are clear; SIMPLIFY when the process has avoidable steps; OBSERVE when the pattern is still unclear.

**Minimum evidence to record:** workflow owner, trigger, inputs, decision rules, exceptions, expected output, review point and rollback path.

**Boundary:** Educational workflow review only — not a client case study, productivity guarantee, security assessment, legal or compliance advice, vendor recommendation or production-change instruction.
