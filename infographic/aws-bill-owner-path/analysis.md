## Main Topic
A safe, owner-led sequence for investigating an unexpected AWS bill before commitments or destructive production changes.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. How to move from an unexplained AWS bill change to a named owner and classified driver.
2. How to choose Act, Investigate or Hold based on evidence.
3. Which proof boundary keeps the checklist educational and no-credentials.

## Target Audience
- **Knowledge Level**: Beginner to intermediate business, finance, product and cloud owners.
- **Context**: An AWS bill has increased and the team needs a safe next step.
- **Expectations**: A forwardable process rather than an unverified savings claim.

## Content Type Analysis
- **Data Structure**: Six ordered process steps.
- **Key Relationships**: Each step supplies evidence or ownership needed by the following decision.
- **Visual Opportunities**: A directional six-node path, owner tag, evidence markers and a three-way Act / Investigate / Hold decision node.
